产品介绍

做电商运营、选品、设计时，经常需要保存商品详情页的图片。但电商平台往往把图片拆散、懒加载、禁用右键保存，手动一张张存又慢又乱。

图片分散难收集

商品图常被拆成多张、藏在懒加载与背景图里，普通「右键另存」只能拿到一张，效率极低。

无法批量保存

平台不提供批量下载入口，几十上百张图只能逐张处理，重复劳动且容易遗漏。

格式不统一

JPG、WebP、PNG 混杂，命名随意。图提取把它们统一转为 PNG 并自动编号，方便归档。

核心功能

从提取到下载，一条链路全部自动完成。

一键提取

自动扫描页面所有商品图，兼容 srcset、data-src、懒加载与背景图。

智能过滤

自动排除图标、Logo、占位图与 1×1 像素图，只保留真正需要的商品图。

集中预览

新标签页网格化展示所有图片，缩略图与尺寸一目了然。

自由勾选

支持全选、反选、按需勾选，想要哪些下载哪些。

统一 PNG

JPG、WebP 自动经 canvas 转为 PNG，输出格式统一。

批量下载

一键保存到本地，文件名自动编号（商品图_001.png），带进度提示。

安装步骤

只需 4 步，无需商店即可加载使用。

  1. 1

    下载并解压

    下载插件压缩包，解压到本地文件夹（例如 D:\imagegrab）。

  2. 2

    打开扩展管理页

    打开 Chrome，地址栏输入 chrome://extensions 回车。

  3. 3

    开启开发者模式

    打开页面右上角的「开发者模式」开关。

  4. 4

    加载扩展

    点击「加载已解压的扩展程序」，选择刚解压出来的文件夹即可完成安装。

准备好开始了吗？

安装「图提取」，从此告别逐张右键保存。
